# Sito personale di Piergiorgio Maruotti

Sito statico per GitHub Pages.

## Pubblicazione
1. Su GitHub crea il repository pubblico `Chtulhu0000.github.io`.
2. Carica `index.html` e `style.css` nella radice del repository (Add file → Upload files → Commit changes).
3. In Settings → Pages, seleziona Deploy from a branch, branch `main`, cartella `/(root)`, quindi Save.
4. Visita https://chtulhu0000.github.io dopo la pubblicazione.

## Da completare prima della promozione
- Inserire i link personali diretti a Google Scholar e ORCID.
- Inserire un recapito professionale scelto dall'autore.
- Verificare i dati bibliografici degli articoli e aggiornare gli stati editoriali quando cambiano.
- Aggiungere eventuali informazioni cliniche solo quando sono definite e verificate.
